Soạn giáo án từ ảnh sách

Chụp các trang sách hoặc vở bài tập rồi gửi lên. Mỗi tiết sẽ thành một file Word (.docx) riêng, có sẵn đáp án.

1Gửi ảnh các trang sách

Chạm để chọn ảnh hoặc kéo thả ảnh vào đây · chọn được nhiều ảnh, theo đúng thứ tự trang

2Thông tin (không bắt buộc)

3Tải file Word

Chưa có giáo án nào. Gửi ảnh rồi bấm “Soạn giáo án”.

Gửi qua Zalo: trên điện thoại, bấm “Tải .docx” → trong bảng chia sẻ hiện ra, chọn Zalo rồi chọn người nhận. Trên máy tính, file lưu vào thư mục Tải xuống, kéo file vào khung chat Zalo.
